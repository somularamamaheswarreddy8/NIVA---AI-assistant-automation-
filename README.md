### Quick Start
1. Double-click `run.bat` or run `.\run.bat` in PowerShell.
2. Or run:
   ```powershell
   python jarvis/main.py
   ```
3. To retrain the statistical NLU model on the 7,960-sample multilingual dataset across 111 intents:
   ```powershell
   python train_nlu.py
   ```
4. To run all unit tests (39 unit tests):
   ```powershell
   python run_tests.py
   ```
5. To run the full system acceptance and NLU verification suite:
   ```powershell
   python run_acceptance_tests.py
   ```
